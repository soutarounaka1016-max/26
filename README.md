# ケツワープ！

3つのレーンをタップし、オリジナルキャラクター「ワープ隊員ドン」を瞬間移動させて障害物を避けるスマホ向けミニゲームです。

## 遊び方

- 行きたいレーンをタップするとワープします。
- ワープ中は障害物をすり抜けられます。
- 障害物が近づいてからワープすると「超ケツワープ」ボーナスが入ります。
- ワープには短いクールダウンがあります。

## 実行

ビルドは不要です。`index.html` をブラウザで開くか、ローカルHTTPサーバーから配信してください。

```bash
python3 -m http.server 4173
```

## 公開

静的ファイルだけで動作します。`main` ブランチへの反映時にGitHub Actionsがテストを実行し、成功後にGitHub Pagesへ公開します。
